## Highlights

- Adds a **Search** tab to every expanded server card. It searches all Sieve
  scripts on that server and shows only matching scripts with a highlighted
  source excerpt.
- Adds **In all scripts** to the text editor's **Find & replace** controls.
  Matches in other scripts are shown above the editor and open the selected
  script with one click.
