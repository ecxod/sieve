## Highlights

- Opens the Inbox **Create Sieve Rule** modal immediately and shows loading or
  connection errors inside the visible modal.
- Removes `require` commands generated by the graphical **Script** editor from
  the rule snippet before checking or saving it. Required capabilities are
  still inserted safely into the selected complete server script.
- Preserves an untouched generated rule when line endings are normalized, so
  changing the template destination mailbox continues to update the graphical
  rule.
- Adds full packaged Electron and XPI-path checks covering modal opening,
  graphical rendering, complete-script validation, and saving.
