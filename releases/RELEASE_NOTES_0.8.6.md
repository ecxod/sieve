## Highlights

- Adds a Spam tab to Thunderbird and Windows for browsing, searching, and
  selecting messages in the spam folder, safely restoring cleaned messages to
  `INBOX`, and inspecting or appending matching Sieve allow/block rules.
- Extends Make pretty with optional leading `require` consolidation and
  optional blank lines after the `require` section and complete
  `if`/`elsif`/`else` chains.
- Adds Windows update management under Settings. It compares the installed
  version with the latest GitHub release and downloads and launches only the
  exact release installer after validating its size and SHA-256 digest.
- Keeps unsaved scripts protected with Save, Discard, and Cancel decisions
  before an update starts.

The Thunderbird extension now requires Thunderbird 121 or newer.
