## Highlights

- Replaces the Inbox rule modal's source-code field with the existing
  graphical editor from the full editor's **Script** tab.
- Parses generated and edited Inbox rules into the established graphical Sieve
  blocks while preserving sender tests and `fileinto :create` destinations.
- Passes the connected server's Sieve capabilities and the selected application
  theme to the embedded graphical editor.
- Keeps server-side full-script validation, stale-script protection, and safe
  append behavior unchanged.
